# Geospatial Analysis: Purple Martins Bird Migration

An environmental data science project exploring the seasonal migration patterns and geographical distributions of Purple Martins.

## Project Objective
This project analyzes spatial tracking data to visualize, map, and model the migratory corridors, staging areas, and seasonal movements of Purple Martins birds.

## Technologies Used
* **Python** (Core Analysis)
* **GeoPandas** & **Pandas** (Spatial & Tabular Data Manipulation)
* **Matplotlib** (Map Visualization)
* **Jupyter Notebook** (Interactive Development Environment)

## Key Features
* Cleaning and processing coordinate-based tracking datasets.
* Visualizing migration routes across geographic regions.
* Analyzing temporal patterns of bird movements.
